================================================================================
  KARAOKE DSP — WINDOWS INSTALLATION GUIDE
================================================================================

QUICK INSTALL (Recommended — Installer .exe)
-----------------------------------------------
  Run:  KaraokeDSP-Setup.exe
  Follow the on-screen wizard.

  NOTE: This is a standalone installer with a graphical wizard.
        It is NOT created by install.ps1 (see below).

POWERSHELL INSTALL (install.ps1)
---------------------------------
  install.ps1 is a script that copies pre-compiled files from the
  payload/ folder to the correct system locations.

  1. Open PowerShell as Administrator
  2. Navigate to this folder
  3. Run:
       powershell -ExecutionPolicy Bypass -File install.ps1

  NOTE: install.ps1 does NOT build the project or create the .exe installer.
        It only copies files that are already compiled.

MANUAL INSTALL
--------------
  1. Copy "Karaoke DSP Console.exe" to your preferred folder
  2. Copy "Karaoke DSP.vst3" folder to:
       %LOCALAPPDATA%\VST3\
     (e.g. C:\Users\YOUR_NAME\AppData\Local\VST3\)
  3. Create a Desktop shortcut if desired

REQUIREMENTS
------------
  OS:     Windows 10 / 11 (64-bit)
  CPU:    x86_64 with SSE2
  RAM:    4 GB recommended
  Audio:  WASAPI or ASIO (ASIO recommended for low latency)

DAW COMPATIBILITY
-----------------
  The VST3 plugin works with all major DAWs:
    - FL Studio
    - Ableton Live
    - Reaper
    - Cubase
    - Studio One
    - Bitwig Studio
    - Cakewalk

SYSTEM AUDIO ROUTING (YouTube, Browser)
-----------------------------------------
  To capture system audio (YouTube, Spotify, Browser):

  Option 1 — VB-Cable (Free):
    1. Install VB-Cable from https://vb-audio.com/Cable/
    2. Set Windows default playback to "CABLE Input"
    3. In your DAW, select "CABLE Output" as track input
    4. Load Karaoke DSP on the track

  Option 2 — VoiceMeeter Banana (Free):
    1. Install from https://vb-audio.com/Voicemeeter/
    2. Route system audio through VoiceMeeter virtual channels
    3. Send virtual output to your DAW / Karaoke DSP

BUILD THE INSTALLER .exe (Developer)
-------------------------------------
  To create KaraokeDSP-Setup.exe from scratch:
    1. Install NSIS on Windows:  https://nsis.sourceforge.io/
    2. Build the project in Release mode
    3. Run:
         makensis /DOUTFILE="KaraokeDSP-Setup.exe" /DBUILD_DIR="Build\win-msvc-release" installer.nsi
    4. Or use:  .\package_nsis.ps1

  NOTE: Building the .exe installer requires Windows + makensis.

UNINSTALL
---------
  Installer .exe:    Settings > Apps > Karaoke DSP > Uninstall
  Script / Manual:   Delete the following folders:
                       %LOCALAPPDATA%\Programs\KaraokeDSP
                       %LOCALAPPDATA%\VST3\Karaoke DSP.vst3
